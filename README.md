# TradeSquare

TradeSquare is an AI-powered B2B trade facilitation platform connecting buyers and suppliers across Rwanda and East Africa.

## Repository layout

- `frontend/` — Flutter client application.
- `backend/` — FastAPI application, AI inference services, and machine-learning development workspace.
- `docs/` — product, architecture, design, API, database, AI/ML, security, and deployment documentation.
- `infrastructure/` — Docker, deployment and operational scripts.

This repository is intentionally scaffolded as a clean project structure without feature implementation.
